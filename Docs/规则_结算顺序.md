# 象群危机 — 结算顺序

> 本册为规则分册之一。全套索引见 `[象群危机规则.md](./象群危机规则.md)`。
> **草稿：** 本结算链按当前实现（`TurnManager` / `ActionService`）梳理，供规则定稿参考；若与实际对局不符，以实际结算为准并修订本文。

---

## 1. 行动开始（轮到某角色时）

按以下顺序逐项结算，**任一步致死后立即判定胜负并换手，不再继续**：

1. **护身符**：清除上次护身符生效遗留的临时能量护盾与「隐匿」（若有）
2. **领袖**：受到 **6 点真伤**；死亡则止
3. **着火** DoT：受到 **10 点法伤（火焰）**，然后持续倒数 1（耗尽则解除）；死亡则止
4. **解除到期状态**：解除以本人为施加者、到期的状态（含他人身上由本人施加的）
5. **沼泽叠毒**：当前行动者若仍站在沼泽，叠 1 层地形中毒（每行动开始至多 1 层）
6. **熔岩**：若站在熔岩格，受到 **20 点真伤**；若因此受伤且未死，获得「着火」1 回合；死亡则止
7. **火焰地块**：身处火焰格立刻获得「着火」（天气为雨天时不生效并已浇灭）
8. **冰地跌倒**：站在冰地时按 20% 判定获得「跌倒」3 回合（装备【滑行靴】免疫）
9. **晕眩跳过**：若持有「晕眩」，清除之并**跳过本行动**（不结算行动内容；行动结束毒伤仍结算）
10. 进入正式行动

> 注：毒伤**不在**行动开始结算，改为**行动结束**时结算（见 §3）。

---

## 2. 行动中

按任意顺序执行，受各自次数限制：

- 移动（至多 1 次）
- 普攻（至多 1 次）
- 射击 / 投掷 / 喷火 / 其它用牌 / 弃置 / 拾取 / 技能等（按条目限制）

**移动落地后**结算：

1. 武装地雷：受到 **15 点法伤**，地雷销毁入弃牌（行动开始已站在其上不触发）
2. 他人投掷的香蕉皮：获得「跌倒」3 回合（施加者=踩到者自己），香蕉皮入弃牌（投掷者自己踩不触发）

---

## 3. 行动结束（结束行动 / 换手）

1. **毒伤**：每层中毒受到 **2 点法伤（毒伤）**（含被晕眩跳过的行动）
2. **定时炸弹**：倒计时 −1（安放时为所选回合×4；到 0 则爆炸）
3. **火焰地块**：持续倒数 −1（铺设时为规则回合×4；到 0 则移除）
4. **濒死计数**：全体濒死者 −1（进入时为 3×4=12 个行动；到 0 则转为「死亡」）
5. 检查胜负 / 平局
6. **红牛**：若预约了额外行动，紧接**连续执行**额外行动（不跑行动开始结算链；重置移动与普攻限制）
7. 换手给下一位存活角色；满四人则进入完整回合结束（§4）

---

## 4. 完整回合结束（四人各行动一次后）

按以下顺序结算：

1. **完整回合状态**：按完整回合计时的状态倒数
2. **技能冷却**：−1
3. **熔岩收缩**：每 5 回合最外圈推进
4. **天气**：锁定窗 / 必变窗判定
5. **虚拟时钟**：时刻 +2 小时，刷新时段与基础能见度
