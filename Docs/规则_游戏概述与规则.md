## 0. 面向状态（设计范式）

《象群危机》是一款 **面向状态** 的回合制对战：就像面向对象语言以对象组织程序，本作用 **状态** 组织规则与角色处境。

| 原则 | 说明 |
|------|------|
| 状态是真相 | 角色「现在怎样」，优先用其所持 **具名状态** 描述（含「濒死」「死亡」） |
| 效果走状态 | 持续增益/减益/控制/生命态，默认写成 **获得 / 刷新 / 解除「×」状态**；数值与结算写在状态条目中 |
| 来源只负责触发 | 卡牌、技能、地形、天气写清「何时施加何种状态、持续多久」；不在来源处重复抄一整段状态效果 |
| 结算读取状态 | 伤害、移动、能见度、能否行动/放技能等，按当前状态集合取值 |
| 特例须显式 | 瞬时结算（如纯扣血、抽牌、弃置）可以不是状态；一旦带有「持续 N 回合 / 直到解除」的含义，应升格为状态 |

状态一览与专节真源：[`规则_卡牌与状态.md`](./规则_卡牌与状态.md) §6。

## 1. 游戏概述

四人各自为战的回合制格子对战。

- 角色：象、人、猴、猫各一名（数值与技能见 [`规则_角色与基础属性.md`](./规则_角色与基础属性.md)）
- 出生位置：象 **(2,2)**、人 **(15,2)**、猴 **(2,15)**、猫 **(15,15)**（地图四角，随地图配置调整）
- 开局：构建共用牌组（含四只玩偶各 **1** 张），**随机散落**到 **18×18** 地图（每格 1 张）；角色**不**开局携带；拾取后生效（持有效果与本命技能等级 +1 见角色分册）；界面以**金色**标识玩偶卡
- 胜利条件（满足其一即可）：
  1. **率先集齐一套玩偶**（象/人/猴/猫玩偶各一）
  2. **成为唯一存活角色**
- 若一次结算中多人同时死亡且无人满足集齐条件 → **平局**
- 若某人同时满足「集齐」与「最后存活」→ 该人获胜（无需区分优先级）

### 1.1 对局模式

| 模式 | 说明 |
|------|------|
| **热座** | 四人同机轮流操作 |
| **AI 对战** | 开局自选一个角色由玩家操控，其余三人由 AI 按同一套规则行动 |
| 联机 | 尚未实装 |

AI 与玩家共用移动 / 攻击 / 用牌 / 胜负判定；AI 当前为启发式策略（治疗、穿甲、射击、近战、投弹、拾取、趋近），不使用未实装技能与复杂连招。

## 2. 基础定义

### 2.1 距离

全文所有「半径 / 范围 / 射程 / 相邻」一律使用 **曼哈顿距离**：

\[
d = |x_1 - x_2| + |y_1 - y_2|
\]

移动、攻击、投掷、爆炸、技能、拾取、弃置等**全部同一套**。

### 2.2 回合与行动

| 术语 | 含义 |
|------|------|
| **行动** | 一名玩家的移动、攻击、弃置、用牌、拾取等全部操作的合计时段（轮到该玩家时开始，至其结束行动并换手） |
| **回合** | 四名玩家 **各行动一次** |

- 虚拟时钟推进、天气刷新、熔岩收缩、技能冷却等，均按 **回合** 计时（见 [`规则_天气与地形.md`](./规则_天气与地形.md)）
- 下文「持续 N 回合」均指上述 **回合**，除非另写「本行动内」
- **由角色施加**的状态「持续 N 回合」：在**施加者此后第 N 次行动开始时**解除（中毒、跌倒等）。例：A 令 B 获得「中毒」持续 1 回合 → 在 A 的**下一次行动开始**时解除（不是第 2 次行动才解除）
- **「着火」例外**：持续在**持有者行动开始**结算伤害时倒数（先扣血，再 −1 持续；耗尽则解除），以便与熔岩「先着火、再熔岩、再上着火」的顺序一致
- 其余按完整回合计时的效果（如肾上腺素、喷火冷却）在 **完整回合结束** 时倒数

### 2.3 行动内容

一次 **行动** 中可执行的行为包括但不限于：

- 移动、攻击、弃置、拾取、使用卡牌/装备、发动技能等
- 可按**任意顺序**执行（受各自次数限制）
- **无**行动开始摸牌；补给来自场上散落与弃置物

### 2.4 次数限制（每行动）

| 行为 | 次数 |
|------|------|
| 移动 | 至多 1 次 |
| **普通攻击（近战普攻）** | 至多 **1** 次 |
| 射击 / 投掷伤害牌 / 喷火等 | **不限**（受弹药与手牌约束） |
| 弃置 | **不限** |
| 其他（拾取、非攻击类用牌、技能等） | 见各条目；无额外写明则按条目本身限制 |

### 2.5 何谓「攻击」

凡 **主动意图使其他角色受到伤害** 的行为，均视为一次 **攻击行为**（用于状态解除、规则用语等）；**即使未造成实际伤害（如 0 物伤）也算攻击行为**。其中仅 **普通近战攻击** 占用「每行动普攻 1 次」槽；射击、投弹等不占用该槽。

**术语区分：「攻击行为」** 为广义（凡主动意图使他人受伤的行为，无论是否造成伤害），用于破隐、状态触发等判定；**「普攻」** 特指占用次数槽的普通近战攻击。

包括但不限于：普攻、射箭、投掷炸弹/高爆炸弹/回旋镖、火焰喷射器、摩托车冲击、会造成掉血的技能等。

**不算攻击**（示例）：

- 弃置、拾取
- 对自己或他人使用血瓶
- 强化剂等纯增益
- **投掷香蕉皮**（投放时不直接造成伤害；他人踩踏触发「跌倒」不属于投放者的攻击行为）

资源与节奏改由 **弹药 / 手牌消耗 / 移动仍限 1 次** 约束，而非攻击次数。

### 2.6 伤害类型

| 类型 | 结算 | 判定「受到攻击 / 被打」 |
|------|------|------------------------|
| **物理伤害（物伤）** | 最终扣血 = `max(0, 伤害值 − 防御)`；其中**防御为结算值，下限 0**（减防叠加不会使防御变为负数） | 仅当最终扣血 **> 0** 时，才算「受到攻击 / 被打」 |
| **法术伤害（法伤）** | 最终扣血 = `⌊伤害值 × (1 − 法抗%)⌋`（**不减防**；法抗为角色基础属性百分比，见角色分册，下限 0） | 凡造成扣血（或按条目结算）均按该条目处理；法伤**不耗甲**；**能量护盾可吸收法伤** |
| **真实伤害（真伤）** | 最终扣血 = 伤害值（**不减防、不耗甲**）；**能量护盾 / 技能护盾不可吸收** | 凡造成扣血均按该条目处理；**真伤一律视为无来源伤害**（结算与日志不记攻击者角色为来源；不因「有来源」触发依赖来源角色的附加交互） |

**凡未明确写「法术伤害 / 法伤」或「真实伤害 / 真伤」的，一律为物伤。**

已明确为法伤的来源：

- 地雷（**移动踩踏**武装地雷所在格时；行动开始已站在其上不触发；弃置在地上的地雷不触发）
- 「着火」状态的行动开始伤害（**10**）
- 火焰喷射器直击
- 「中毒」状态的行动结束伤害（每层 **2**）
- **猫的近战普攻**（见角色分册；装备近战武器时武器加攻仍计入）

已明确为真伤的来源（均为无来源）：

- 「领袖」状态的行动开始损耗（**6**）
- 熔岩地块站立伤害（行动开始 **20**；其附加的「着火」仍为法伤）
- 【诅咒之刃】第 x 次使用：目标 **2x**、自身 **x**
- 荆棘护甲反弹的真伤

普攻物伤公式：

\[
最终扣血 = \max(0,\ 攻击 − 防御)
\]

- 当 `攻击 ≤ 防御` → 扣血为 0 → **不算**「受到攻击」
- **木甲 / 铁甲**（装备中）：只要受到一次物伤结算（护盾未完全吸收时），**无论最终扣血大于、等于或小于防御（含扣血为 0）**，均消耗 **1** 次防御耐久
- 能量护盾完全吸收该次物伤或法伤时：不扣血、不耗甲耐久（护盾自身按条消耗次数）；**不吸收真伤**

## 3. 背包与拾取

（属性含义总表见 [`规则_角色与基础属性.md`](./规则_角色与基础属性.md)。）

### 3.1 背包与重量

- 每个物品占用 **1** 点背包容量（弹药：一张 = 一支 = 重量 1；同种合并时按支数计）
- **行动中允许超重**：即使当前负重已达/超过容量，仍可拾取、获得物品
- **超重时无法结束行动**：若负重仍大于容量，点击「结束行动」会被拒绝并提示背包超载；须先主动弃置物品到半径 1 范围内，直至负重 ≤ 容量后才能换手（无单独的强制弃置阶段）
- 行动中任意时刻可主动弃置（次数不限）到半径 1 内**任意格**（含自己脚下，也可弃到其他角色脚下）

### 3.2 拾取

- 可拾取半径 1 范围内（含脚下）的掉落物
- 濒死期间不可拾取（见 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md)「濒死」状态）
- 拾取**不受当前容量限制**（可因此超重；见 §3.1）

## 4. 流程摘要

1. 游戏开始：生成地图；四角色出生；构建共用牌组（含四只玩偶各 1 张）并**散落到全图每格 1 张**
2. 按固定顺序轮流行动（热座或联机均可）
3. 每名玩家 **行动** 开始时（顺序摘要）：
   - 解除以本人为施加者、到期的状态
   - **着火等状态伤害优先结算**，再结算熔岩 **20** 真伤（可再施加着火，着火为法伤）等；冰地跌倒判定见分册
   - 若持有「晕眩」→ 跳过本行动（见状态分册）
   - 进行本行动（移动 ≤1、普攻 ≤1、射击/投弹等不限、弃置/拾取不限等；行动中可超重；**不**行动开始摸牌）
   - **移动落地后**：若目标格有武装地雷 / 他人投掷的香蕉皮 → 按踩踏结算（行动开始时已站在陷阱上不触发）
   - 结束行动：若负重 > 容量则无法结束（提示背包超载），须先弃置至 ≤ 容量
4. 四名玩家各行动一次计为 **1 回合**；据此推进天气 / 昼夜 / 熔岩 / 冷却；定时炸弹等在 **本回合结束** 结算
5. 检查胜负与平局

## 5. 领袖宣言（特殊技能）

- 每名玩家限发动 **一次**
- 发动条件：某角色持有 **任意三个玩偶**（含自己本命），且 **剩下的一个玩偶在其他玩家身上**（在地上 **不触发**）
- 发动后：
  1. 获得「领袖」状态，持续 **10** 回合（效果见 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md)）
  2. 立刻**从场上随机获得至多 5 张牌**（不限距离、不消耗行动、允许超重；不足 5 张则取现有）
  3. 立刻得知剩下那只玩偶的具体位置（持有者位置）

## 6. 术语速查

| 术语 | 含义 |
|------|------|
| 面向状态 | 以具名状态组织持续效果与角色处境的设计范式（见 §0） |
| 状态 | 挂在角色上的具名效果条目；可有持续回合或直到解除条件 |
| 行动 | 一名玩家移动、攻击、弃置、用牌、拾取等操作的合计时段 |
| 回合 | 四名玩家各行动一次 |
| 物伤 | `max(0, 值 − 防)`；未标明法伤/真伤者皆为此 |
| 法伤 | `⌊伤害 × (1 − 法抗%)⌋`；不减防、不耗甲；能量护盾可吸收 |
| 真伤 | 不减防、不耗甲；护盾不可吸收 |
| 攻击（次数） | **普攻每行动 ≤1**；射击/投弹等不限次（受弹药/手牌约束） |
| 被打 / 受到攻击 | 通常指最终扣血 > 0 的物伤（及条目规定的扣血）；0 物伤不算 |
| 弃置 | 丢到场上；不进弃牌堆，直到熔岩吞噬 |
| 弃牌堆 | 结算完毕/销毁的牌；需要抽牌时若库空可洗回 |
