## 1. 地图

- 大小：**18 × 18**
- 开局 **全部为非熔岩**（无熔岩）
- 地块类型与目标比例（生成用**种子生长**：每种特殊地形 1～2 个连通斑块，约各占 10%；四角出生点附近 5×5 保留普通）：

| 地块 | 比例 | 效果 | 色块（示意） |
|------|------|------|--------------|
| 普通 | ~50% | 无 | 亮草绿棋盘格 |
| 沙地 | ~10% | 移动力 −1；**法抗 −10%** | 土黄 |
| 沼泽 | ~10% | **进入**叠 1 层「中毒」；之后每轮**自己的行动开始**若仍站在沼泽再叠 1 层（总层数受中毒 3 层上限）；**离开**清除全部**地形**毒层（角色施加的中毒层保留）；**法抗 −20%** | 浊橄榄褐 |
| 冰地 | ~10% | 移动力 +1；**行动开始时** 20% 获得「跌倒」状态，持续 3 回合（装备【滑行靴】时免疫该跌倒，且冰上移动力额外 +2）；**不会铺上格子火焰** | **淡蓝** |
| 丛林 | ~10% | **进入**无火焰的该格时获得「隐匿」状态；**有火焰的丛林不提供隐匿**；**法抗 +20%** | 浓绿 |
| 高地 | ~10% | 攻击 +3，攻击范围 +1，防御 +3 | 棕灰岩面；**相对地面抬升 0.25**（有崖壁） |
说明：冰地 / 沙地等改的是 **移动力**；滑板 / 摩托车的移动力加成与地形修正 **叠加** 得到最终可移动格数。水系不在设计范围内。

高地提供的「攻击范围 +1」计入远程/近战的**外部增益**（见 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md)「射程叠加」）。

熔岩收缩时会**覆盖**原有地形为熔岩（橙红）。

## 2. 熔岩收缩

- 每 **5 回合**（完整四人对局轮次）：最外层一圈非熔岩变为熔岩
- 持续收缩，直到 **全部地块为熔岩**
- 因开局无熔岩，第 5 回合推进后才出现最外圈熔岩，故初始出生点开局不会是熔岩
- 站在熔岩上的角色：在其 **行动开始**（着火等状态结算**之后**）受到 **20 点真伤**；若因此受到伤害，获得「着火」状态，持续 1 回合（着火伤害仍为法伤）
- 熔岩覆盖某格时：该格掉落物进入弃牌堆

## 3. 虚拟时钟与时段

- 第 **1** 回合虚拟时刻为 **6:00**；每推进 **1 完整回合**（四人各行动一次）时刻 **+2 小时**（`H = (6 + (R−1)×2) mod 24`，显示为 `H:00`）
- 同一完整回合内，四名玩家共享同一时刻
- 时段与**时段×天气能见度矩阵**（曼哈顿半径；**无限** = 全图半径，实现上为 40）：

| 时段 \ 天气 | 晴天 | 雨天 | 雾天 |
|-------------|------|------|------|
| 清晨（4:00–7:59） | **无限** | **无限** | **6** |
| 白天（8:00–15:59） | **无限** | **无限** | **8** |
| 黄昏（16:00–19:59） | **无限** | **无限** | **6** |
| 黑夜（20:00–3:59） | **5** | **4** | **3** |

说明：开局第 1 回合为 **6:00 / 清晨 / 晴天**，能见度为**无限**。

## 4. 能见度结算

- **矩阵能见度**：取当前虚拟时钟时段 × 当前天气（见 §3）；挂件与状态在此之上叠加
- **移动限制**：角色**不可**将落点选在自身当前能见度范围之外（移动提示与 AI 同步遵守）；**能见度为 0 时完全无法移动（定身）**
- 状态下限优先：**致盲** = 0；**濒死** = 1；**中毒**（至少一层）= 2
- **橡胶雨衣**（装备）：雨天能见度按**同时段晴天**矩阵结算（并免疫雨天防 −3）；不耗耐久
- **夜视镜**（装备）：仅在**黑夜**生效——晴天能见度 **+3**（5→8）、雨天 **+2**（4→6）、雾天 **+1**（3→4）；白天/晨昏不生效
- **望远镜**（装备）：**非黑夜**生效——白天/晨昏的**雾天**能见度 **+2**；晴/雨/雾天均可**看见隐匿**角色（仍须在能见度内），并可**查看其他可见角色的背包**；黑夜不生效
- **迷雾表现**：热座按当前行动者刷新视野；AI 对战按玩家所选角色刷新（荣誉模式）；视野外遮罩随**天气气质**变化——**雾天**为浓白团雾；**晴天**为天空色空气透视（按时段偏暖杏/晴空蓝/暮橙/夜幕）；**雨天**为冷灰蓝薄幕。均不可辨认视野外地形（不做探索记忆）

相关状态（「中毒」「致盲」「隐匿」「濒死」等）见 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md)。

## 5. 天气

### 5.1 效果

| 天气 | 效果 |
|------|------|
| 晴天 | 能见度见 §3 矩阵；无额外攻防修正 |
| 雨天 | 全员防御 −3；能见度见 §3 矩阵；**法抗 +25%**（装备【橡胶雨衣】者免疫防御/能见度雨天项且不因此耗雨衣耐久，法抗加成仍生效）；立刻解除所有「着火」状态；**立刻浇灭**场上所有格子火焰（含【打火机】燃瓶、【火焰喷射器】路径等留下的火焰）；雨天期间**不会获得**「着火」、**不会新铺**格子火焰 |
| 雾天 | 能见度见 §3 矩阵；**法抗 +10%** |

法抗合计：基础（角色） + 地形（丛林 +20% / 沙地 −10% / 沼泽 −20%） + 天气（雨 +25% / 雾 +10%），**下限 0%**。

能见度叠加：先取时段×天气矩阵，再叠雨衣 / 夜视镜 / 望远镜，再被濒死/中毒/致盲等压到下限。

### 5.2 自动变更（非管理员）

- 开局默认 **晴天**；开局视为一次天气变更
- 每次变更后：其后 **5 回合内**天气不再改变（含变更当回合起算的第 5 回合仍不变）；在变更后的第 **6～10** 完整回合（含）内**必然再变更一次**（开局变更时随机预定该回合号）
- **晴天**下一次变更时，**必然**变为雨天或雾天（各 50%）
- 雨天 / 雾天变更时：在「不同于当前」的天气中均匀随机（可回到晴天）
- **天气弹**（晴天弹 / 雨天弹 / 雾天弹）强制切换天气时，同样计为一次变更并**重新预定**下次自动变更回合（管理员模式除外）

### 5.3 管理员模式

- **不**进行自动天气变更
- 可随时**任选**天气（晴 / 雨 / 雾，非轮换）；切到雨天时同样立刻灭火
- 可随时**任选**时段（清晨 / 白天 / 黄昏 / 黑夜），覆盖虚拟时钟显示与能见度基础（不影响回合推进、熔岩等）
