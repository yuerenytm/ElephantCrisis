# 象群危机 — 天气与地形

> 本册为规则分册之一。全套索引见 [`象群危机规则.md`](./象群危机规则.md)。  
> 「回合」均指完整四人对局一轮，见 [`规则_游戏概述与规则.md`](./规则_游戏概述与规则.md)。

**本册范围：** 地图与地块、熔岩收缩、昼夜、能见度结算、天气。

> **实现进度：** 熔岩收缩、能见度、多样地形（种子生长）、虚拟时钟与时段能见度、天气逻辑已落地；**水系不做**；高地抬升与天气表现等美术 **0.9**（见版本计划书）。

## 1. 地图

- 大小：**18 × 18**
- 开局 **全部为非熔岩**（无熔岩）
- 地块类型与目标比例（生成用**种子生长**：每种特殊地形 1～2 个连通斑块，约各占 10%；四角出生点附近 5×5 保留普通）：

| 地块 | 比例 | 效果 | 色块（示意） |
|------|------|------|--------------|
| 普通 | ~50% | 无 | 亮草绿棋盘格 |
| 沙地 | ~10% | 移动力 −1 | 土黄 |
| 沼泽 | ~10% | 移动力 −2，防御 −3 | 浊橄榄褐 |
| 冰地 | ~10% | 移动力 +1；**行动开始时** 20% 获得「跌倒」状态，持续 3 回合 | **淡蓝** |
| 丛林 | ~10% | **进入**该格时获得「隐匿」状态 | 浓绿 |
| 高地 | ~10% | 攻击 +3，攻击范围 +1，防御 +3 | 棕灰 |
说明：冰地 / 沙地等改的是 **移动力**；滑板 / 摩托车的移动力加成与地形修正 **叠加** 得到最终可移动格数。水系不在设计范围内。

高地提供的「攻击范围 +1」计入远程/近战的**外部增益**（见 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md)「射程叠加」）。

熔岩收缩时会**覆盖**原有地形为熔岩（橙红）。

## 2. 熔岩收缩

- 每 **5 回合**（完整四人对局轮次）：最外层一圈非熔岩变为熔岩
- 持续收缩，直到 **全部地块为熔岩**
- 因开局无熔岩，第 5 回合推进后才出现最外圈熔岩，故初始出生点开局不会是熔岩
- 站在熔岩上的角色：在其 **行动开始**（着火等状态结算**之后**）受到 **20 点真伤**；若因此受到伤害，获得「着火」状态，持续 1 回合（着火伤害仍为法伤）
- 熔岩覆盖某格时：该格掉落物进入弃牌堆

---

## 3. 虚拟时钟与时段

- 第 **1** 回合虚拟时刻为 **6:00**；每推进 **1 完整回合**（四人各行动一次）时刻 **+2 小时**（`H = (6 + (R−1)×2) mod 24`，显示为 `H:00`）
- 同一完整回合内，四名玩家共享同一时刻
- 时段与**基础能见度**（曼哈顿半径）：

| 时段 | 时刻范围 | 基础能见度 |
|------|----------|------------|
| 白天 | 8:00–15:59 | **10** |
| 黄昏 | 16:00–19:59 | **7** |
| 黑夜 | 20:00–3:59 | **5** |
| 清晨 | 4:00–7:59 | **8** |

说明：开局第 1 回合为 **6:00 / 清晨**，基础能见度 **8**（不是白天 10）。

---

## 4. 能见度结算

- **基础能见度**：取自当前虚拟时钟时段（见 §3）；再叠装备与状态
- **移动限制**：角色**不可**将落点选在自身当前能见度范围之外（移动提示与 AI 同步遵守）
- 多方修正并存时：**取最小值优先**（再参与后续减法修正时，减在该最小值上）
- 能见度下限按各效果处理（如「致盲」状态为 0；「濒死」「中毒」为 1）
- **夜视镜**（装备）：仅在**黑夜**时段，将基础能见度按 **8** 结算（清晨/白天/黄昏不受影响）
- **迷雾表现**：热座按当前行动者刷新视野；AI 对战按玩家所选角色刷新（荣誉模式）；视野外迷雾**不透明**，不可辨认地形色（不做探索记忆）

相关状态（「中毒」「致盲」「隐匿」「濒死」等）见 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md)。

## 5. 天气

### 5.1 效果

| 天气 | 效果 |
|------|------|
| 晴天 | 无额外攻防 / 能见度修正（沿用时段基础能见度） |
| 雨天 | 全员防御 −3，能见度 −1；立刻解除所有「着火」状态；雨天期间**不会获得**「着火」状态 |
| 雾天 | 全员能见度 −2 |

能见度叠加：先取时段基础（及夜视镜），再叠天气，再被濒死/中毒等压到下限。

### 5.2 自动变更（非管理员）

- 开局默认 **晴天**；开局视为一次天气变更
- 每次变更后：其后 **5 回合内**天气不再改变（含变更当回合起算的第 5 回合仍不变）；在变更后的第 **6～10** 完整回合（含）内**必然再变更一次**（开局变更时随机预定该回合号）
- **晴天**下一次变更时，**必然**变为雨天或雾天（各 50%）
- 雨天 / 雾天变更时：在「不同于当前」的天气中均匀随机（可回到晴天）

### 5.3 管理员模式

- **不**进行自动天气变更
- 可随时自由切换天气（界面循环：晴→雨→雾→晴）；切到雨天时同样立刻灭火
