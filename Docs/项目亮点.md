# 《象群危机》项目亮点

> 面向对外介绍、作品集与里程碑复盘的摘要。  
> 规则细节以 [`象群危机规则.md`](./象群危机规则.md) 及分册为准；版本进度见 [`版本计划书_0.5至1.0.md`](./版本计划书_0.5至1.0.md)。  
> **口径：** 下列条目默认指 **现行已落地（0.9 已收口；0.10 打磨中）**；文末单列「规划中」以免混谈。

## 一句话定位

四人各自为战的回合制格子对战：共用限量牌库争夺四只金色玩偶，或在熔岩收缩的地图上成为最后存活者；规则以 **状态** 组织，地形与迷雾改变每局走位。

---

## 核心设计亮点

| 亮点 | 一句话 |
|------|--------|
| **面向状态** | 濒死、着火、隐匿、领袖等持续效果统一为具名状态，卡牌/技能/地形只负责施加与结算读取，避免散落特例 |
| **双胜负路径** | 「集齐四只玩偶」与「唯一存活」二选一成立即可胜；同时死亡无人集齐则平局 |
| **共用限量牌库** | 全体共享一副有印数的牌库，抽空洗入弃牌；弃置物留在场上可拾取，熔岩吞格才进弃牌 |
| **金色玩偶博弈** | 四只本命玩偶各 1 张入牌库（不开局携带）；持有效果 + 本命技能等级；是胜利物也是成长资源 |
| **领袖宣言** | 持三偶且缺偶在他人身上时，限一次发动：领袖状态、从场上取牌、得知缺偶位置——高风险高回报的终局技能 |


---

## 地图与压力

| 亮点 | 一句话 |
|------|--------|
| **种子生长随机地图** | 用种子生长生成沙/沼/冰/丛/高地等**连通斑块**（约各 10%），而非逐格噪声；出生角保留普通地 |
| **地形即战术** | 沙地减速、沼泽施加中毒（离地解除）、冰地加速但可能跌倒、进丛林隐匿、高地攻防与射程加成 |
| **熔岩收缩** | 每 5 完整回合最外圈变熔岩并向内推进；站立结算真伤并可着火，强制中心对抗 |
| **虚拟时钟 + 时段能见度** | 第1回合6:00、每回合+2小时；清晨8/白天10/黄昏7/黑夜5 |
| **天气锁定窗** | 开局晴天；变更后5回合锁定、第6–10回合内必变；晴必转雨/雾；雨灭火降防 |
| **能见度 + 迷雾** | 按时段基础半径，不可移出视野；热座按行动者、AI 对战按玩家角色刷新迷雾（荣誉模式） |
| **视野外隐藏** | 迷雾外单位与掉落物不可见，配合丛林隐匿形成信息差 |

## 角色与成长

| 亮点 | 一句话 |
|------|--------|
| **四角色非对称** | 象威慑光环 / 人强化自增益 / 猴机动与骚扰 / 猫隐匿潜入——同规则不同打法 |
| **技能等级成长** | 本命玩偶与技能升级卡（集齐 3 张）提升技能等级，上限 3 |
| **装备四槽** | 武器 / 防具 / 载具 / 挂件各至多 1 件，木甲与铁甲互斥等同槽取舍 |
| **弹药一张一支** | 弓箭/毒箭/火箭按张计数与重量，射击即消耗，远程节奏由弹药约束 |
| **弩跨行动蓄力** | 蓄力与射击不可同一行动完成，形成可预判的高攻远程窗口 |

---

## 战斗与资源节奏

| 亮点 | 一句话 |
|------|--------|
| **物伤 / 法伤 / 真伤三分** | 物伤减防耗甲；法伤不减防（护盾可吸）；真伤穿盾穿甲（领袖 DoT、熔岩站立） |
| **能量护盾吸法伤** | 防具槽护盾可全额吸收物伤或法伤，但不能挡真伤 |
| **行动中可超重** | 抽牌与拾取不受容量卡住；超重时无法结束行动，须先弃置到容量内 |
| **掉落即战场资源** | 主动弃置留在地上供人捡；濒死掉落装备；踩踏触发地雷/香蕉皮（站着不动不触发） |
| **定时炸弹信息差** | 仅安装者可见，按完整回合计时结算 |
| **摩托车冲击** | 直线冲刺造成物伤并晕眩，且占用本行动的移动次数 |

## 生命态与控制

| 亮点 | 一句话 |
|------|--------|
| **濒死不是秒死** | 血量归零进入濒死：移 1、视野 1、掉落装备，仅能用脚下血瓶自救，形成抢救/补刀窗口 |
| **行动开始结算链** | 着火优先 → 领袖真伤 → 熔岩真伤 → 冰地跌倒等，顺序写清可复现 |
| **状态持续按施加者** | 多数控制/中毒于施加者第 N 次行动开始解除；着火例外按持有者行动倒数 |

## 可直接复用的对外短句（示例）

适合放在 README、答辩 PPT 或商店简介：

1. 使用**种子生长**生成地块连通的随机地图，沙沼冰丛高地成片而非散点噪声。  
2. **面向状态**的规则架构：持续效果一律具名状态，来源只触发、结算只读状态。  
3. **双胜利条件**：集齐四只金色玩偶，或在熔岩收缩中成为最后存活者。  
4. **共用限量牌库 + 场上掉落**：弃置不是消失，而是别人的机会。  
5. **能见度迷雾与丛林隐匿**：看不见就不能走过去，信息本身就是资源。  
6. **濒死自救窗口**：倒地掉装、移速与视野骤降，血瓶抢人一命。  
7. **领袖宣言**：三偶在手、一偶在敌，终局一搏改写局势。  
8. **物伤 / 法伤 / 真伤**分工明确：护盾挡得住法伤，挡不住熔岩与领袖的真伤。
