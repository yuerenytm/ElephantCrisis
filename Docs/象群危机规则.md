# 象群危机 — 规则文档（索引）

> 整理自原《象群危机》设计纲要与规则澄清（Q&A）。  
> 正文已拆为四册；**若分册冲突，以本索引所列现行版本口径与较新修订说明为准。**

**设计范式：面向状态（Status-Oriented）。**  
本游戏以 **状态** 为规则与实现的核心抽象——角色在任意时刻的处境，由其所持 **状态集合** 解释（含「濒死」「死亡」等生命态，以及跌倒、着火、领袖等）。卡牌、技能、地形、天气的首要职责是 **施加 / 刷新 / 解除状态**，或读取状态以改变结算；持续效果不另起一套「散落的特例文案」，而归入具名状态。详见 [`规则_游戏概述与规则.md`](./规则_游戏概述与规则.md) §0 与 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md) §6。

**数值口径（现行）：** 血量、攻击、防御、背包，以及与之对应的伤害 / 治疗 / 攻防修正，相对最初纲要 **×3**；**移动力、射程、半径、回合数、次数类** 不放大。强化类效果中：攻/防按 ×3，移动仍按原幅度。

**产品基线：** **0.5.0** 可玩原型已完成；**现行版本 0.7.2**（地形种子生长 · 能见度起步，见下方修订记录）。后续规划见 [`版本计划书_0.5至1.0.md`](./版本计划书_0.5至1.0.md)。

## 修订记录

旧文档曾使用 `1.0`–`1.12` 作为规则修订号。自本拆分起，统一映射为产品向的 **`0.1.0`–`0.5.0`**（0.5 可玩基线）。**自技能/玩偶里程碑起使用 `0.6.x`，不再递增 0.5.x。**

| 现行版本 | 原编号 | 说明 |
|----------|--------|------|
| **0.1.0** | 1.0 + 1.1 | **规则奠基**：原始设计纲要；合并 Q&A（伤害类型、曼哈顿、回合口径、攻击定义、濒死、牌库/弃牌、射程叠加、甲与护盾、地雷、跌倒、冲击占用等） |
| **0.2.0** | 1.2 + 1.3 | **数值与射程**：血/攻/防/背包及对应伤害治疗与攻防修正 ×3；移动/射程/半径不放大；强化剂与人形技能改为攻防+3、移动+1；默认射程不再计入远程叠加；弓/弩射程 = 武器贡献 + 高地等增益 |
