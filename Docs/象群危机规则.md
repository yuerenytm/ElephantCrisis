# 象群危机 — 规则文档

> 整理自《象群危机 1.0》设计纲要，以及后续规则澄清（Q&A）。  
> 若旧文档与本文冲突，**以本文为准**。  
>  
> **数值口径（当前）：** 血量、攻击、防御、背包，以及与之对应的伤害 / 治疗 / 攻防修正，相对初版 **×3**；**移动力、射程、半径、回合数、次数类** 不放大。强化类效果中：攻/防按 ×3，移动仍按原幅度。

## 1. 游戏概述

四人各自为战的回合制格子对战。

- 角色：象、人、猴、猫各一名
- 开局：每名角色携带**自己的本命玩偶**
- 胜利条件（满足其一即可）：
  1. **率先集齐一套玩偶**（象/人/猴/猫玩偶各一）
  2. **成为唯一存活角色**
- 若一次结算中多人同时死亡且无人满足集齐条件 → **平局**
- 若某人同时满足「集齐」与「最后存活」→ 该人获胜（无需区分优先级）

### 1.1 对局模式

| 模式 | 说明 |
|------|------|
| **热座** | 四人同机轮流操作 |
| **AI 对战** | 开局自选一个角色由玩家操控，其余三人由 AI 按同一套规则行动 |
| 联机 | 尚未实装 |

AI 与玩家共用移动 / 攻击 / 用牌 / 胜负判定；AI 当前为启发式策略（治疗、穿甲、射击、近战、投弹、拾取、趋近），不使用未实装技能与复杂连招。

## 2. 基础定义

### 2.1 距离

全文所有「半径 / 范围 / 射程 / 相邻」一律使用 **曼哈顿距离**：

\[
d = |x_1 - x_2| + |y_1 - y_2|
\]

移动、攻击、投掷、爆炸、技能、拾取、弃置等**全部同一套**。

### 2.2 回合

本文「回合」均指 **完整一轮**：四名玩家各行动一次。

- 天气刷新、昼夜切换、熔岩收缩、技能冷却、状态持续等，均按此口径计时
- 单个玩家的一次行动称为 **行动回合**（或「该玩家的回合」）

### 2.3 行动

玩家在自己的行动回合内可执行的行为统称 **行动**，包括但不限于：

- 移动、攻击、弃置、拾取、使用卡牌/装备、发动技能等
- 行动阶段可按**任意顺序**执行上述行为（受各自次数限制）

### 2.4 次数限制（每行动回合）

| 行为 | 次数 |
|------|------|
| 移动 | 至多 1 次 |
| **普通攻击（近战普攻）** | 至多 **1** 次 |
| 射击 / 投掷伤害牌 / 喷火等 | **不限**（受弹药与手牌约束） |
| 弃置 | **不限** |
| 其他（拾取、非攻击类用牌、技能等） | 见各条目；无额外写明则按条目本身限制 |

### 2.5 何谓「攻击」

凡 **主动意图使其他角色受到伤害** 的行为，均视为一次 **攻击行为**（用于状态解除、规则用语等）。其中仅 **普通近战攻击** 占用「每回合普攻 1 次」槽；射击、投弹等不占用该槽。

包括但不限于：普攻、射箭、投掷炸弹/高爆炸弹、火焰喷射器、摩托车冲击、会造成掉血的技能等。

**不算攻击**（示例）：

- 弃置、拾取
- 对自己或他人使用血瓶
- 强化剂等纯增益
- **跌倒卡**（没有人会因该卡直接掉血）

资源与节奏改由 **弹药 / 手牌消耗 / 移动仍限 1 次** 约束，而非攻击次数。

### 2.6 伤害类型

| 类型 | 结算 | 判定「受到攻击 / 被打」 |
|------|------|------------------------|
| **物理伤害（物伤）** | 最终扣血 = `max(0, 伤害值 − 防御)` | 仅当最终扣血 **> 0** 时，才算「受到攻击 / 被打」 |
| **真实伤害（真伤）** | 最终扣血 = 伤害值（**不减防**） | 凡造成扣血（或按条目结算）均按该条目处理；真伤**不耗甲**；能量护盾**不挡且不消耗次数** |

**凡未明确写「真实伤害 / 真伤」的，一律为物伤。**

已明确为真伤的来源：

- 地雷（踩到所在格时）
- 熔岩地块（每回合开始）
- 领袖宣言的每回合损耗

普攻物伤公式：

\[
最终扣血 = \max(0,\ 攻击 − 防御)
\]

- 当 `攻击 ≤ 防御` → 扣血为 0 → **不算**「受到攻击」
- 0 扣血的普攻：**不耗**目标护甲耐久

## 3. 基础属性

| 属性 | 含义 |
|------|------|
| 移动力 | 本行动回合可移动的曼哈顿格数上限（再与移动速度等叠加，见 §8） |
| 血量 | 血量 **< 1** 时进入濒死 |
| 攻击 | 参与物伤计算的进攻值 |
| 防御 | 减免物伤 |
| 背包容量 | 物品占用容量的上限 |
| 能见度 | 可见范围内的地形、掉落物、非隐匿角色 |

### 3.1 背包与重量

- 默认：每个物品占用 **1** 点背包容量
- 例外：**弓箭重量为 0.33**（即 **3 支弓箭 = 1** 点容量）
- **行动中允许超重**：即使当前负重已达/超过容量，仍可抽牌、拾取、获得物品
- **结束行动前必须清负重**：本行动回合结束时，若负重仍大于容量，必须先弃置物品到半径 1 范围内，直至负重 ≤ 容量后，才能真正换手
- 行动阶段任意时刻也可主动弃置（次数不限）到半径 1 内**任意格**（含自己脚下，也可弃到其他角色脚下）

### 3.2 拾取

- 可拾取半径 1 范围内（含脚下）的掉落物
- 濒死期间不可拾取（见 §6）
- 拾取**不受当前容量限制**（可因此超重；见 §3.1）

## 5. 卡牌与物品

### 5.1 牌库结构（现行约定）

- 全体玩家 **共用一副限量牌库**（数量以卡面印数为准，见下表）
- 每名玩家在自己的行动回合开始时，从牌库 **随机获得 1 张** 卡牌
- **结算完毕** 的牌进入 **弃牌堆**，例如：
  - 次数用尽的甲
  - 引爆/结算完毕的爆炸物（按条目）
  - **射出的弓箭**
  - 触发后的地雷（踩踏结算后销毁入弃牌）
  - 使用完毕的消耗品等
- **玩家主动弃置到场上的卡牌不算进弃牌堆**：留在场上供人拾取；直至所在格被 **熔岩覆盖**，该格掉落物进入弃牌堆
- 牌库抽空后：将弃牌堆 **洗牌**，重新作为牌库

### 5.3 射击规则

- **必须拥有弓或弩** 才能射击；弓箭/毒箭/火箭为弹药
- 实际攻击力 = `角色攻击 + 武器加攻（弓+2 / 弩+10）`
- 物伤结算：`max(0, 实际攻击力 − 目标防御)`
- 射击不限次数（仍受弹药约束）
- 射出的弓箭（含毒箭/火箭作为弹药消耗）进入弃牌堆（按弓箭合并规则折算）

### 5.4 射程叠加

- **角色默认射程（1）** 只用于近战，**不计入**弓/弩等远程叠加
- 远程最终射程 = `武器射程贡献 + 外部增益（如高地 +1）`
- 近战最终射程 = `默认射程 1 + 外部增益`

示例：平原持弓 → 射程 **3**；高地持弓 → **3 + 1 = 4**（不再是旧算法的 1+3+1=5）。

跌倒卡等「使用玩家射程」的效果：香蕉皮投掷使用**近战攻击距离**（默认 1 + 外部增益）。

## 6. 状态效果

| 状态 | 效果 |
|------|------|
| 跌倒 | 防御 −3，速度 −1；持续 3 完整回合（香蕉皮踩踏等） |
| 中毒 | 攻击/防御 −3，移动力 −1；视线范围变为半径 1 |
| 隐匿 | 除与你半径 1 相邻者外，其他角色不知你的位置且无法攻击你；**进行攻击后解除**（一切可能造成别人掉血的主动行为均视为攻击） |
| 着火 | 每回合受到 **15 点物伤**（减防） |
| 晕眩 | 跳过下一次行动 |
| 致盲 | 能见度变为 0 |
| 濒死 | 见下节 |
| 领袖宣言 | 见 §10 |

### 6.1 濒死

触发：血量 **< 1**。

效果：

- 移动力变为 **1**
- **其余属性变为 0**（含攻击、防御、背包容量等）
- **能见度变为 1**
- 解除其他所有效果
- 所有物品掉落在当前格子（穿戴中的甲/护盾一并掉落并 **解除穿戴**）；脱离濒死前 **不可拾取**
- **不能发动技能**

死亡条件（满足其一）：

1. 再次受到会扣血的伤害来源（含普攻、炸弹、着火、熔岩等 **一切可能扣血** 的行为；但 `攻≤防` 的 0 物伤 **不触发**）
2. 进入濒死后 **3 回合内**（含进入的当回合起算）没有玩家对其使用血瓶

救治：

- 血瓶回复按其数值（小 +9 / 大 +15）
- **自己可以对濒死的自己使用血瓶**
- 脱离濒死后：恢复为 **角色基础攻防移 + 永久强化（强化剂等）**；若玩偶、甲等仍在身上则继续生效，若已掉落则不生效（需重新拾取）

## 7. 地图、昼夜与熔岩

### 7.1 地图

- 大小：**18 × 18**
- 开局 **全部为非熔岩**（无熔岩）
- 地块类型与生成比例（后续实现地形时启用）：

| 地块 | 比例 | 效果 |
|------|------|------|
| 普通 | 50% | 无 |
| 沙地 | 10% | 移动力 −1 |
| 沼泽 | 10% | 移动力 −2，防御 −3 |
| 冰地 | 10% | 移动力 +1；每回合 20% 获得跌倒 |
| 丛林 | 10% | 获得隐匿 |
| 高地 | 10% | 攻击 +3，攻击范围 +1，防御 +3 |

说明：冰地 / 沙地等改的是 **移动力**；滑板 / 摩托车的「移动速度」与移动力 **叠加** 得到最终可移动格数。

### 7.2 熔岩收缩

- 每 **5 回合**（完整四人对局轮次）：最外层一圈非熔岩变为熔岩
- 持续收缩，直到 **全部地块为熔岩**
- 因开局无熔岩，第 5 回合推进后才出现最外圈熔岩，故初始出生点开局不会是熔岩
- 站在熔岩上的角色：在其 **行动回合开始** 受到 **9 点真伤**
- 熔岩覆盖某格时：该格掉落物进入弃牌堆

### 7.3 昼夜

- 每 **5 回合** 白天 / 夜晚切换
- 白天基础可视半径 **10**
- 夜晚基础可视半径 **5**

### 7.4 能见度结算

- 多方修正并存时：**取最小值优先**（再参与后续减法修正时，减在该最小值上）
- 能见度下限按各效果处理（如致盲为 0）
- 夜视镜：夜晚可视变为半径 5（与其他规则一并按最小值原则结算）

## 8. 天气

每 **5 回合** 随机生成一种天气：

| 天气 | 概率 | 效果 |
|------|------|------|
| 晴天 | 50% | 无额外 buff/debuff；能见度视为无限（仍受「最小值优先」与其他强制效果约束） |
| 雨天 | 25% | 全员防御 −3，能见度 −1；立刻解除所有着火，雨天期间不会获得着火 |
| 雾天 | 25% | 全员能见度 −2 |

约束：**不能连续三次生成同一种天气**  
（即：若最近两次已相同，则第三次必须换一种。对时间线而言，等价于任意连续 3 次不能全相同。）

## 9. 流程摘要

1. 游戏开始：生成地图；四角色出生；各带本命玩偶；构建共用牌库
2. 按固定顺序轮流行动（热座或联机均可）
3. 每名玩家行动回合开始时：
   - 若站在熔岩上 → 结算 9 真伤
   - 从牌库抽 1 张（牌库空则洗入弃牌堆再抽；若仍无牌则跳过）
   - 进入行动阶段（移动 ≤1、普攻 ≤1、射击/投弹等不限、弃置不限等；行动中可超重）
   - 结束行动回合前：若负重 > 容量，强制弃置至 ≤ 容量后再换手
4. 完整四人对局计 1 回合；据此推进天气 / 昼夜 / 熔岩 / 冷却 / 持续效果
5. 检查胜负与平局

## 10. 领袖宣言

- 每名玩家限一次
- 获得条件：某角色得到 **任意三个玩偶**（含自己本命），且 **剩下的一个玩偶在其他玩家身上**（在地上 **不触发**）
- 发动后：
  - 10 回合内：攻击/防御 +9，移动力 +3
  - 获得五张牌
  - 立刻得知剩下那只玩偶的具体位置（持有者位置）
  - 每回合受到 **6 点真伤**

## 11. 术语速查

| 术语 | 含义 |
|------|------|
| 回合 | 四人各行动一次的完整一轮 |
| 行动回合 | 当前玩家的一次行动时段 |
| 物伤 | `max(0, 值 − 防)`；未标明真伤者皆为此 |
| 真伤 | 不减防 |
| 攻击（次数） | **普攻每回合 ≤1**；射击/投弹等不限次（受弹药/手牌约束） |
| 被打 / 受到攻击 | 通常指最终扣血 > 0 的物伤（及条目规定的扣血）；0 物伤不算 |
| 弃置 | 丢到场上；不进弃牌堆，直到熔岩吞噬 |
| 弃牌堆 | 结算完毕/销毁的牌；牌库空时洗回 |
