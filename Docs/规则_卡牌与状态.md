# 象群危机 — 卡牌与状态

> 本册为规则分册之一。全套索引见 [`象群危机规则.md`](./象群危机规则.md)。  
> 物伤 / 法伤与「攻击」定义见 [`规则_游戏概述与规则.md`](./规则_游戏概述与规则.md)。

**本册范围：** 卡牌分类、牌库结构、卡牌一览、射击与射程、状态效果（含「濒死」「死亡」）。

## 1. 卡牌分类

牌库与背包中的卡牌分为三类：**装备卡**、**道具卡**、**功能卡**。

| 大类 | 判定口径 | 子类 |
|------|----------|------|
| **装备卡** | **非一次性**（可反复持有/使用；可有耐久、冷却或有限次数，但本身不是「用完即从规则上定义为消耗牌」的一次性施放） | 武器 / 防具 / 载具 / 挂件 |
| **道具卡** | **一次性**；用于**角色（自身或他人）或场地**（伤害、控制、治疗、布置陷阱等） | — |
| **功能卡** | **一次性**，且效果**仅服务自身成长/强化**（升级、永久属性、临时自身增益等） | — |

### 1.1 装备卡子类

| 子类 | 判定口径 | 现行示例 | 计划中示例 |
|------|----------|----------|------------|
| **武器** | 可主动对他人造成伤害的非一次性卡 | 弓、弩、火焰喷射器、匕首、长剑、破甲刃、诅咒之刃 | 短刀、榴弹炮、血刃等 |
| **防具** | 可减免伤害的非一次性卡 | 木甲、铁甲、橡胶雨衣、荆棘护甲、战术背心、能量护盾 | — |
| **载具** | 加快移动的非一次性卡 | 滑板、摩托车、滑行靴 | — |
| **挂件** | 提供辅助增益，或实现非战斗功能的非一次性卡 | 夜视镜、抢夺勾爪、护身符 | — |

**装备槽规则：** 武器 / 防具 / 载具 / 挂件 **各至多同时装备 1 件**。例如木甲与铁甲不可同时装备，但防具可与弩（武器）同时装备。

说明：

- **弹药**（弓箭 / 毒箭 / 火箭）本身不是装备：随射击消耗，规则上归入 **道具卡**（一次性耗材，服务于对他人的攻击）。
- **抢夺勾爪** 归类为挂件；现行效果为使用一次后损毁（耐久 1 的挂件），不以「道具卡」论。
- **血瓶** 归类为 **道具卡**（治疗）；可对自身或攻击范围内其他角色使用。
- **本命玩偶** 各 1 张入共用牌组并开局散落到地图（特殊胜利物，不归入装备/道具/功能三类）；持有效果见角色分册；界面以**金色**标识。

### 1.2 道具卡与功能卡

| 大类 | 判定口径 | 现行示例 |
|------|----------|----------|
| **道具卡** | 一次性；用于角色或场地（伤害、控制、治疗、布置等） | 炸弹、高爆炸弹、定时炸弹、闪光弹、回旋镖、地雷、香蕉皮、小/大血瓶、牛奶、晴/雨/雾天弹；以及弹药（弓箭/毒箭/火箭） |
| **功能卡** | 一次性；仅服务自身成长/强化 | 技能升级卡、强化剂、肾上腺素、红牛 |

## 2. 牌库结构（现行约定）

- 全体玩家 **共用一副限量牌组**（数量以卡面印数为准，见下表；除四只玩偶各 1 张外，其余卡牌印数相对初期草案已翻倍）。印数合计 **324**，与地图 **18×18** 格数一致
- **开局**：将全部牌**随机散落**到地图上，**每格至多 1 张**（恰好铺满）；角色**不开局携带**任何牌
- **取消**「行动开始从牌库摸 1 张」；补给主要靠**拾取**场上散落/弃置物（半径见行动规则）
- **结算完毕** 的牌进入 **弃牌堆**，例如：
  - 次数用尽的甲
  - 引爆/结算完毕的爆炸物（按条目）
  - **射出的弓箭**（按弹药合并规则折算）
  - 触发后的武装地雷（踩踏结算后销毁入弃牌）
  - 使用完毕的功能卡 / 道具卡等
- **玩家主动弃置到场上的卡牌不算进弃牌堆**：留在场上供人拾取；直至所在格被 **熔岩覆盖**，该格掉落物进入弃牌堆
- 牌库（抽牌堆）在开局散落后通常为空；若仍有牌（或弃牌洗回），仅供**管理员领取**、人技能「摸牌」等少数效果使用。弃牌堆在需要时仍可**洗入**抽牌堆

## 4. 射击规则

- **必须装备弓或弩**（装备 · 武器）才能射击；弓箭/毒箭/火箭为弹药（道具卡）
- 实际攻击力 = `角色攻击 + 武器加攻（弓+2 / 弩+10）`
- 物伤结算：`max(0, 实际攻击力 − 目标防御)`；目标防御为结算值，**下限 0**
- 弓：装备后可直接射击（耗 1 弹药）
- 弩：装备后须先**蓄力**；**下一次行动**起方可射击（耗 1 弹药）；蓄力与射击不可在同一行动内
- 射击不限次数（仍受弹药与弩蓄力约束）
- 射出的弹药每 1 支对应 1 张牌进入弃牌堆

## 5. 射程叠加

- **角色默认射程（1）** 只用于近战，**不计入**弓/弩等远程叠加
- 远程最终射程 = `武器射程贡献 + 外部增益（如高地 +1）`
- 近战最终射程 = `近战武器距离（无武器则为默认 1）+ 外部增益`；隐匿目标仍须邻接才能被近战选中

示例：平原持弓 → 射程 **3**；高地持弓 → **3 + 1 = 4**。

香蕉皮、地雷等「使用玩家射程」的效果：放置/投掷使用**近战攻击距离**（默认 1 + 外部增益）。

## 6. 状态效果（规则真源）

本游戏为 **面向状态** 设计（见 [`规则_游戏概述与规则.md`](./规则_游戏概述与规则.md) §0）：持续效果与生命态以本节为唯一细则真源。

施加一般状态时，统一表述为：**获得「状态名」状态，持续 N 回合**。此处「持续 N 回合」的计时口径见 [`规则_游戏概述与规则.md`](./规则_游戏概述与规则.md) §2.2（由角色施加 → 于施加者之后第 N 次行动开始时解除；踩踏类跌倒的施加者=踩到者自己）。若仅本玩家时段内有效，另写「本行动内」。卡牌 / 技能 / 地形 / 天气条只写施加与持续，**不重复抄**状态数值与细则。

| 状态 | 效果（摘要） |
|------|------|
| 跌倒 | 防御 −3，移动力 −1 |
| 中毒 | **可叠加，最多 3 层**（角色毒与地形毒**共用同一上限**）。每层：攻击/防御 −2，移动力 −2；**行动结束**每层受到 **2 点法伤（毒伤）**（含晕眩跳过本次行动）。只要持有至少 1 层，视线范围变为半径 **2**。沼泽：**进入**叠 1 层地形毒，之后每轮**自己行动开始**仍在沼泽再叠 1 层；离开沼泽清除全部地形毒层。**已满 3 层时新施加不生效（不覆盖已有层）**。角色施加的各层仍按「持续 N 回合」于各自施加者行动开始解除 |
| 隐匿 | 除与你半径 1 相邻者外，其他角色不知你的位置且无法攻击你；进行攻击后解除（凡主动意图使他人受到伤害的行为，即使 0 物伤未造成伤害，也视为攻击并解除隐匿）。**始终持续，不按回合倒数**，直到攻击破隐或其它效果解除；**丛林来源**的隐匿在**离开丛林**时解除（离开后不再自动获得，需再次进入丛林）；护身符的隐匿持续到你的**下一次行动开始**。对不可见的隐匿者：移动预判不因其占格而阻挡；若落入其所在格，移动者弹至「来向」邻格（主轴优先；等距对角线则两正交来向邻格随机）并消耗本次移动；**不解除**该隐匿（弹至邻格后仅邻接者可见，避免位置广播给全场） |

| 晕眩 | **你的行动开始时，若你拥有该状态，跳过你的行动**（持续 1 回合即可覆盖「下一次行动」） |
| 致盲 | 能见度变为 0 |
| 肾上腺素 | 移动力 +2，攻击 +3；**不可叠加**（再次获得时刷新持续时间，不叠加数值） |
| 领袖 | 攻击/防御 +9，移动力 +3；**行动开始时**受到 **6 点真伤**。由特殊技能「领袖宣言」发动时获得 |
| 濒死 | 见 §6.1 |
| 死亡 | 见 §6.2 |

### 6.1 「濒死」状态

**获得：** 血量 **< 1** 时，获得「濒死」状态。

**效果：**

- 移动力变为 **1**（与全局规则一致：存活时移动力**最低为 1**，满层中毒等减益亦不可把移动力压到 0）
- **其余属性不变**（攻击、防御、背包容量等保持获得「濒死」前的数值与修正）
- **能见度变为 1**
- **不解除**其他已有状态与效果
- 所有物品掉落在当前格子（穿戴中的装备一并掉落并 **解除穿戴**）
- **不可拾取**物品
- **不可发动技能**
- **不可使用卡牌**（例外见下）

**本行动特例（自救）：** 轮到自己行动时，若**自己所在格子**上有血瓶（小/大），可以**直接使用该格上的血瓶**（无需拾取）；不可使用其他卡牌。

**转为「死亡」状态**（满足其一即可）：

1. 再次受到会扣血的伤害来源（含普攻、炸弹、「着火」状态、熔岩等 **一切可能扣血** 的行为；但 `攻≤防` 的 0 物伤 **不触发**）
2. 进入「濒死」后 **3 回合内**（含进入时所属行动所在的当回合起算）没有玩家对其使用血瓶

**解除「濒死」：**

- 血瓶回复按其数值（小 +9 / 大 +15）；血量回升至 **≥ 1** 后解除「濒死」
- 他人仍可在规则允许时对濒死者使用血瓶；自己仅能按上款使用**脚下**血瓶
- 解除后：以当前仍生效的基础攻防移、永久强化、未解除状态等继续结算；已掉落的物品需重新拾取后方能再用

### 6.2 「死亡」状态

**获得：** 由「濒死」按 §6.1 的转化条件转入；获得「死亡」时解除「濒死」。

**效果：**

- **从场上移除该角色**
- **跳过该角色的行动**（轮到该角色时直接跳过，不进行行动内容）
