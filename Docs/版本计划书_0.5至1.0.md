## 1. 目标与原则

### 1.1 产品目标

按里程碑补齐角色差异（技能/玩偶）、能见度、地形、天气与昼夜、2.5D/UI，经 **0.10 打磨平衡** 后发布 **1.0**。设计范式为 **面向状态**。

### 1.2 版本原则

1. **规则先行，版本兑现**  
2. **先系统后皮肤**（天气/高地等美术进 0.9）  
3. **可玩即交付**  
4. **范围写死**：教程 → 1.2/1.3；联机 → 2.0；未实装新卡 → 1.0 窗口；玩偶与技能**改版**另议  

---

## 3. 分版本说明书

### 3.1 v0.5 — 基线（已完成）

热座 / AI、卡牌与背包、熔岩、状态与濒死等核心闭环。不含技能实装、完整能见度、地形、天气昼夜、2.5D。

---

### 3.2 v0.6 — 技能与玩偶

| 项 | 说明 |
|----|------|
| 技能 | **按现行规则实装**四角色技能（改版另议，本版不阻塞） |
| 玩偶 | 现行持有效果 + 本命技能等级 +1 |
| 领袖宣言 | **已实装**（特殊技能，限一次） |
| 技能升级卡 | **已实装**（牌库 12 张；集齐 3 张可使技能等级 +1，上限 3） |
| 能见度 | **→ 0.7** |
| AI | 会用基础技能（象光环自动；人/猫优先；猴可简化）；会尝试领袖宣言与升级卡 |
| 猫隐匿破隐 | 昼夜未实装前按**白天**半径判定；完整昼夜随 **0.8** |
| 闪光弹等 | 与其他未实装新卡一并 **1.0 窗口** |

**不做：** 能见度/迷雾；技能/玩偶大改版；教程；联机。

---

### 3.3 v0.7 — 地形与能见度

六类地块（种子生长连通斑块）与移动/战斗修正；**能见度结算 + 迷雾**；丛林隐匿；热座荣誉模式；与熔岩共存。水系不做。  
**高地抬升等立体表现 → 0.9。** 本版色块即可（冰地淡蓝）。

---

### 3.4 v0.8 — 天气与昼夜

**已落地：** 虚拟时钟；时段能见度；天气（开局晴、变更后 5 回合锁定、第 6～10 回合必变、晴必转雨/雾、雨灭火与防/视修正、管理员自由切换）。  
**天气/昼夜美术与氛围 → 0.9。** 本版 UI 标明时刻/时段/天气即可。

---

### 3.5 v0.9 — 2.5D 与 UI / 美术

| 项 | 说明 |
|----|------|
| 2.5D | 镜头与层感；**高地抬升**；点击校准 |
| UI | 主菜单、对局 HUD、背包、战报、结算等正规化 |
| 美术 | 角色/地块/图标；**天气与昼夜氛围** |
| 动效 / 音频 | 按精力纳入；音频缺口可进 0.10 清单 |

**0.9.0 已落地（表现切片）：** 轻微等距斜视正交相机；XZ 地面；高地 Y=+0.25 + 崖壁；六类地形程序化顶面；射线点选；单位/掉落/陷阱跟高。  
**0.9.1 已落地：** `UiTheme` 统一皮肤；主菜单与对局 HUD 边框面板（顶栏/战报/行动/背包）。  
**0.9.2 已落地：** 现代独立风重绘（少边框、半透明阴影、色板收敛、地图优先布局、字号/留白）。  
**0.9.3 已落地：** 木纹/羊皮纸桌面切换；正视（yaw0）相机；右键拖移、滚轮缩放。  
**仍待 0.9：** 天气/昼夜氛围、图标、Hover 动效、品质色等（外援建议第二/三阶段）。

---

### 3.6 v0.10 — 打磨 / 平衡（缓冲版）

| 项 | 说明 |
|----|------|

| 手感 | 操作与节奏小修 |
| **不含** | 教程（→ 1.2/1.3）；联机（→ 2.0） |

## 6. v1.0 退出标准（收紧后）

1. 技能（现行）、玩偶效果、能见度、地形、昼夜、天气、熔岩可感知且与文档一致  
2. 领袖宣言、技能升级卡可用（**0.6.0 已落地**）  
3. 热座 + AI 可完整结束并判胜负  
4. 0.9 表现达到「可演示」自定标准；0.10 无阻断级缺陷  
5. **不要求**教程、联机、技能大改版完成  

---

## 7. 还有问题吗？（简答）

**大方向没问题，可以按此执行。** 执行层注意：

1. **0.6** 含四技能、玩偶、领袖宣言、技能升级卡；能见度仍归 **0.7**。  
2. **猫隐匿** 在 0.8 前按白天半径破隐。  
3. **0.10 与 1.0 新卡**：新卡宜有上限，避免冲掉平衡结论。  
4. **版本号**：规则修订用 `0.6.x` 起跳，**不再写 0.5.x**；对内 git tag 建议 `v0.6.0`。
