> 供设计挑选的**卡牌创意池**。与 [`规则_卡牌与状态.md`](./规则_卡牌与状态.md) 中**已列卡牌**无关；选定后按分类写入正文并实装。  
> 总索引：[`象群危机规则.md`](./象群危机规则.md)。计划上新卡窗口主要在 **1.0**（0.10 以打磨为主，本池可并行选型）。  
> 数值按当前 ×3 口径草拟，可再调。  
> 分类口径：装备（武器/防具/载具/挂件）· 道具 · 功能。

**已进正文、勿重复提案：** 匕首、长剑、弓弩喷火、甲/盾（含**橡胶雨衣**、**荆棘护甲**）、滑板摩托、夜视镜/**望远镜**/勾爪、炸弹类、闪光弹、**回旋镖**、地雷、香蕉皮、血瓶、**牛奶**、技能升级/强化剂/肾上腺素、弹药与四玩偶、**汽油瓶/打火机（及喷火耗油）** 等。

**本轮补池方向：** 熔岩缩圈博弈、天气/时段博弈、濒死交互、信息战、地形特化（沼/冰/高地）、FFA 搅局；避免再叠「又一块反伤甲 / 又一个清毒药」。

---

## 设计目标

1. **补齐手段差异**：近战爆发、廉价远程、直线、控位、视野、生存、机动、资源交互。  
2. **不全是武器**：防具/载具/挂件/治疗控制/成长卡要占一半以上提案。  
3. **用印数 · 自残 · 耐久 · 条件触发** 控强度，而不是叠纯数值。  
4. **文案与现卡严格区分**（尤其陷阱：地雷 / 香蕉皮 / 新陷阱夹；解控：牛奶已清中毒/着火/跌倒）。

## F. 可选节奏约束（与上表独立）

攻击不限次后若过爆，可另选：

1. **伤害类手牌每行动最多打出 N 张**（建议 N=2）；普攻不计入  
2. **同名攻击牌每回合限用 1 次**  
3. **不加全局约束**，只靠印数与耗材

## G. 选型备忘（实装前）

- 「手里剑 / 回旋镖」射程与弓弩同一套：**卡面/武器贡献 + 高地等，不含角色默认 1**。  
- 陷阱夹 ≠ 香蕉皮（投掷隐身、仅跌倒）≠ 地雷（放置武装、法伤）。  
- 致盲 / 迷雾区依赖现有能见度与「致盲」状态；闪光弹已实装，新卡勿叠同质。  
- **假玩偶**不得计入集齐胜；界面勿用真玩偶金色。  
- **牛奶已实装**（清中毒/着火/跌倒）：草案勿再提「解毒剂」同质卡；冰袋只清着火+临时防。  
- **荆棘护甲已实装**（近战实伤 50% 真伤反弹）：勿再提「荆棘披风」固定物伤反弹。  
- 0.10 打磨期建议每版最多点选 **4～6 张**进包，先用 LogicSim / balance 看胜率与死亡率。  
- **制作 / 采集链**（§H）测试成本高：新状态机 + 地图交互 + 经济循环，宜整包进 **1.x**，勿拆进 0.10 热修。  
- **【树林】≠【丛林】**：丛林已实装（进入隐匿）；树林是另一套「可砍伐 + 站立防 +3」地形，文案与表现必须明显区分。  
- **斧头 / 木头 / 树林 / 制作台**（§H.1）与汽油井链可并行记池，但实装宜整包（地形计数 + 武器交互 + 产出卡 + 工位配方）。  
- **急救喷雾**会强改濒死节奏，选型时先定「能否自救 / 敌方能否被救起来继续抢偶」。  
- **赏金帖 / 偶探罗盘**偏 FFA 信息战，注意与领袖宣言「得知缺偶位置」的差异（帖=集火，罗盘=距离）。

| **斧头** | 3～4（牌库） | 见 §A：装备近战，攻击 **+3**；对邻格/本格树林发动砍伐（是否占用普攻、每行动几次——选型时定） | 伐木钥匙 |
| **木头** | 产出物（不进初始库） | 每次成功砍伐获得 **1** 张【木头】（或砍满 3 次才给 1～3 张——待定）。持有后可在【制作台】消耗 | 木质素材 |
| **制作台**（木作） | 地图互动点（可与 H.0 制作台合并为同一工位、分配方页） | 消耗【木头】制作**木质工具/装备**（草案举例：【弓】、【木甲】等已有牌；是否还能做滑板/箭矢等另表）。产出进手牌或掉落在工位格；配方耗木数量与是否耗行动待定 | 资源转化 |

**规则备忘（选型时拍板）：**

1. 砍伐进度是**格子属性**（全员共享 0/3）还是「每人独立」——建议**格共享**，先砍先拿木、第三人拿平地。  
2. 砍伐是否可在有人站在该格时进行；熔岩覆盖树林时进度清零还是直接变熔岩。  
3. 制作出台的弓/木甲与牌库印数并存时：制作产牌是否**不进弃牌循环**、或制作时从弃牌/牌外区「生成」副本——避免牌库张数膨胀失控。  
4. AI：何时抢砍、是否守制作台，优先级需单独启发式。

**建议实装包：** 树林地形 + 斧头 + 木头 + 制作台木作配方（至少弓/木甲）一次进；勿只上斧头无树林。

### H.3 冰地 · 水池 · 冰系采集（新记 · 未实装）

> 与现有【冰地】（移动 +1 / 跌倒）并列的冰主题；采集工具并入 §A【冰镐】（战斗 + 采集一体）；先不实装。冰系伤害作为**法伤**的子标签（与火焰并列），天然受法抗百分比减免、护盾可吸收、不耗甲。

| 要素 | 建议印数 / 生成 | 草案效果 | 定位 |
|------|-----------------|----------|------|
| **水池** | 新**地形**（由冰地采集转化；也可考虑地图生成比例——待定） | 【冰镐】采集**冰地**后该格变为**水池**。水池格效果待定：移动力惩罚（涉水减速？禁止踏入？）；可否被【冰块】冻回冰地；熔岩收缩覆盖水池的处理 | 可转化地形 |
| **冰块** | 产出物（不进初始库） | 新**道具**；可投掷（射程同投掷类）：对命中目标造成 **冰系法伤**；或掷向**水池**格将其**冻回冰地**（地形还原）；是否可对自身使用（清着火？）——待定 | 冰系弹药 / 地形还原 |
| **冰系伤害（法伤）** | — | 归入**法伤**大类：受法抗百分比减免、能量护盾可吸收、不耗甲耐久；日志/结算沿用法伤路径（`kind=magic`），`via` 标 `ice` 便于后续出冰系卡 | 法伤子类型 |

**规则备忘（选型时拍板）：**

1. **水池地形语义**：对移动/能见度的影响、能否被踩入、与熔岩收缩的交互（水池被熔岩覆盖？）——选型时一并定。
2. **冰镐（合并版）**：原 §A 冰镐（冰地战斗特化）+ 镐子（采集/地形转化）已合并为一把——战斗（对冰地目标 +6 物伤）与采集（冰地→水池 + 产冰块）同卡，勿再拆两把。
3. **冰块投掷**：是否要求可见目标；落点为格而非角色时（区域冰面 / 冻地形）的判定。
4. **AI**：何时采集、冰块价值的启发式（进攻投掷 vs 地形还原）。

### H.4 闪避体系（新记 · 远期战斗系统）

> 战斗深度向的系统改动；与现有「防御减伤」「护盾吸收」并列的**第三种防御语义**；先不实装。

| 要素 | 草案 | 测试压力 |
|------|------|----------|
| **闪避** | 角色获得「闪避」值 / 状态：受到**物伤**（或仅近战普攻）时按概率**完全免疫**本次伤害；与防御 / 护盾 / 法抗的结算先后待定 | 高（新结算层 + 概率 + AI / 反馈） |
| **来源** | 角色基础闪避？装备 / 状态 / 技能临时闪避（如猫隐匿期间近战闪避加成？）；天气 / 地形（雾天闪避？）——待定 | 中 |
| **克星与边界** | 法伤 / 真伤是否可被闪避；远程 / 近战是否一致——决定强度上限 | 高 |

**规则备忘（选型时拍板）：**

1. **结算链定位**：闪避与现有「护盾 → 减防 → 耗甲」的先后（先闪避后护盾？还是护盾优先？），需在 [`规则_结算顺序.md`](./规则_结算顺序.md) 明确定位。
2. **概率型结算的测试影响**：方差大，对 LogicSim 基线 / 平衡统计敏感；建议给「伪随机 / 保底」或限定来源（如仅近战普攻），避免全伤种概率免伤过强。
3. **与隐匿 / 猫的协同**：猫已有隐匿（不可被攻击），若再加闪避需避免效果重叠。
